# Проигрыш и цели

<!-- источник: концепция v0.1, раздел 9 «Проигрыш и цели» -->

`[РЕШЕНО]` По модели Game Dev Tycoon: разорение возможно и означает конец. Игра прощает много, но не всё.

**Три способа умереть:**

1. **Деньги.** Баланс в минусе 8 недель подряд. Зарплаты тикают каждую неделю независимо от того, играешь ты или нет. Купил звезду на пике и не выиграл ничего — вот и спираль.
2. **Люди.** Мораль орги на дне → все игроки уходят одновременно → некого выставить → исключение из лиги. Уникальная для киберспорта смерть, страшнее денежной.
3. **Репутация.** Накопил скандалов → спонсоры разбежались → нет денег. Медленная смерть, видно за 10 недель.

**Мягкий провал:** сезонная цель («топ-8 региона»). Провал не убивает и сам по себе никуда не роняет. Вниз по лестнице лиг падают по правилам ступени — вылет из нижних мест лиги, потеря квалификации на «мир», — а не за проваленную цель, `design/ladder.md`.

**Как в Game Dev Tycoon:** остаться маленькой орг-однодисциплинником с пятью пацанами всю игру — законная стратегия. Победа не только в масштабе.
