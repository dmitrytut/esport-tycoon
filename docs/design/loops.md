# Петли: неделя, сезон, организация

<!-- источник: концепция v0.1, раздел 2 «Ядро: три петли» -->

## Петля недели (минуты)
Задал план → жмёшь «дальше» → игра останавливается на событии/матче/патче → реагируешь → дальше.

## Петля сезона (20–35 минут)
24 недели → 2 крупных турнира + 6–8 матчей → итоговый отчёт → трансферное окно → цель на следующий сезон.

## Петля организации (часы)
Найти игрока → собрать состав → развить → удержать (или не удержать) → продать на пике → вырасти в инфраструктуре → взять следующую дисциплину.

Последний пункт важен: карьера киберспортсмена коротка, и цикл «звезда стареет — надо продавать вовремя» даёт игре хребет.
