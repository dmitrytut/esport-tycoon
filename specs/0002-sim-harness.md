# Спека 0002: sim-harness и отчёт по балансу

**Статус:** черновик
**Зависит от:** 0001
**Дизайн-источник:** `docs/design/week.md`, `docs/design/failure.md`, `docs/adr/0002`

## Задача

Консольный прогон игры без графики: N сезонов по заданным сидам с ботом-политикой вместо
пользователя. На выходе — машиночитаемая сводка и человекочитаемый отчёт. Это основной
инструмент балансировки и защита от регрессий; строится рано, до любого UI.

## Вне рамок

- Графика и любой ввод
- Умный ИИ-менеджер: достаточно 3–4 простых политик (жадная на деньги, жадная на скилл,
  случайная, сбалансированная)
- Онлайн

## Поведение

1. Запуск: количество сезонов, диапазон сидов, политика, конфиг дисциплины.
2. Каждый прогон полностью детерминирован сидом.
3. Сбор метрик: доля разорений и на какой неделе, распределение итоговых мест,
   средняя энергия и мораль по неделям, частота срывов, доход по источникам,
   доля недель каждого типа, длина карьеры игрока.
4. Отчёт: сравнение с предыдущим прогоном (baseline в репозитории), явное указание
   сдвигов больше порога.

## Критерии приёмки

- [ ] 10 000 сезонов прогоняются без падений
- [ ] повторный запуск с тем же сидом даёт идентичные метрики
- [ ] отчёт показывает дельту к baseline и помечает значимые сдвиги
- [ ] прогон запускается одной командой и не требует движка
