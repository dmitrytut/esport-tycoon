# Спека 0003: недельный цикл

**Статус:** черновик
**Зависит от:** 0001
**Дизайн-источник:** `docs/design/week.md`, `docs/design/loops.md`

## Задача

Тик недели: пул слотов, мероприятия, расход и восстановление энергии, мораль,
план на блок из 4–6 недель, кнопка «дальше» с остановкой только на значимом,
классификация недель по весу (тихая / обычная / матчевая / турнирная).

## Вне рамок

- Матч (0004), события (0005), экономика сверх начисления и списания денег
- UI

## Открытые вопросы

- Что именно считается «значимым» для остановки — список условий надо зафиксировать явно,
  иначе игра будет тормозить на пустяках или проглатывать важное.
