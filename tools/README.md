# tools/

Инструменты разработки. Не зависят от движка (см. `docs/adr/0000`), запускаются из консоли.

| Инструмент | Что делает | Статус |
|---|---|---|
| `validate_content` | проверяет `content/` по схемам + ссылочную целостность: событие ссылается на существующую черту, дисциплина — на существующие статы, регион — на существующий пул имён | не написан |
| `sim_harness` | прогон N сезонов без графики по заданным сидам, см. `specs/0002` | не написан |
| `balance_report` | сравнение метрик прогона с baseline, подсветка значимых сдвигов | не написан |
| `lint_core` | запрещённые доменные слова в `src/core/`, см. `docs/adr/0001` | не написан |

Первым нужен `validate_content`: без него генерация контента агентами неуправляема.
Он не требует ни движка, ни ядра.
